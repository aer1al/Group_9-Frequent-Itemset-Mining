# SPMF tham chiếu

`spmf.jar` là bản phát hành Java bên ngoài, chỉ dùng để đối chiếu kết quả và thời gian chạy.
Tải tệp từ: <https://www.philippe-fournier-viger.com/spmf/index.php?link=download.php>

From VS Code Terminal:

```powershell
python -m scripts.setup_spmf
java -version
python -m scripts.run_spmf --jar tools/spmf.jar
```
