# Dữ liệu cho ứng dụng

Tải dữ liệu ứng dụng bằng lệnh:

```powershell
python -m scripts.download_data --names ecommerce ecommerce_names optdigits
```

Nguồn và thông tin truy xuất của từng tệp được mô tả trong `DATA_SOURCES.md`. Tệp UCI Optdigits có 64 giá trị pixel và một nhãn cho mỗi ảnh; nhãn không được dùng để tạo codebook hoặc khai thác itemset.
